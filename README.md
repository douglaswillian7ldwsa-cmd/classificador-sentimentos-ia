#  Classificador de Sentimentos com IA

Projeto desenvolvido em Python para praticar conceitos de Inteligência Artificial e Machine Learning.

##  Objetivo

Criar um modelo capaz de analisar frases e classificá-las como positivas ou negativas por meio de técnicas de processamento de linguagem natural.

##  Tecnologias utilizadas

- Python
- Scikit-learn
- Machine Learning
- Processamento de Linguagem Natural (PLN)

##  Como funciona

O modelo utiliza exemplos de frases para aprender padrões e realizar previsões sobre novos textos.

##  Aprendizados

- Treinamento de modelos de classificação.
- Manipulação de textos com Python.
- Introdução ao aprendizado de máquina.
- Organização e documentação de projetos no GitHub.

##  Próximas melhorias
